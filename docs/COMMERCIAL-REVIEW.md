아래 시각·연출 평가는 위 제품의 공개 화면과 월영의 실제 화면을 비교해 내린 제작상의 판단이며, 공식 자료가 월영의 품질을 평가한 것은 아니다.

- 전투 영역: v2는 전장을 28vh로 줄이고 위아래에 웹 페이지형 제목과 정보 패널을 배치했다. 전장 자체를 화면의 중심으로 키우고 HUD·손패를 전장 안에 배치한다. 데스크톱에서는 전투에 들어온 순간 스크롤 없이 적과 카드가 보이는 것이 기준이다.
- 카드: 모든 카드가 같은 종이 프레임과 캐릭터 그림이다. 무공은 청옥·먹색·붉은 인장·검보 장식, 판타지는 심청·금속·룬·보석 장식으로 나눈다. 월하참은 인물 대신 검끝에서 뻗는 초승달 검기를 보여 준다.
- 파쇄: 큰 다각형 6개가 흩어져 종이가 접히는 느낌이었다. 밝은 균열이 분기하고 작은 삼각 조각과 픽셀 파편으로 폭발하며 그 중심에서 기술이 형상화되어야 한다.
- 공격: 종류와 무관하게 가는 선 하나와 작은 도형이 날아갔다. 검기는 넓은 초승달 베기·연속 검흔, 별빛은 다중 창·마법진, 유성우는 하늘 낙하, 얼음은 빙정 분출, 방어는 여러 동료의 장벽처럼 기술별 동작을 분리한다.
- 타격: 준비 → 방출 → 타격 정지 → 반동 → 잔상 순서를 적용하고, 강한 기술은 더 큰 이펙트와 짧은 화면 연출을 사용한다. 단순한 카드에도 장시간 컷신을 붙이지 않는다.
- 재미: 연출만 바뀌어도 상용 게임의 빌드 다양성이 생기지는 않는다. 이번에는 합격 필살기의 선택과 결과 예측을 보강한다. 이후에는 카드/적 패턴/유물/경로/런 시작 선택의 확장이 필요하다.

목표는 이번 수정본에서 화면·카드·스킬 구분과 전투의 선택을 실제로 개선하는 것이다. 상용 수준에 도달했다는 평가는 플레이 경험과 추가 콘텐츠 검증 없이는 하지 않는다. 다른 게임의 카드/그래픽 파일은 복제하지 않는다.
