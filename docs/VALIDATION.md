# 검증 기록

2026-10-05, 전투·카드 개편 v4 기준.

- **엔진 검사 28개 통과**: 기존 20개에 합격 게이지 누적·상한·턴 유지, 상태를 변경하지 않는 예상 피해, 불가능한 절기 거부, 단일 절기의 방어 계산·중복 소비 방지, 전체 공격과 생존 동료 방어/회복의 구분, 이전 저장의 게이지 이관·범위 검증, 솔로 시작·순차 합류·합류 전 카드 제한과 솔로 저장을 추가했다.
- **실제 6/4프레임 검증 통과**: 브라우저에서 공격 시트 인덱스 0–5와 기술 인덱스 0–3의 재생을 수집했다. 몬스터 공격도 0–5를 확인했다.
- **프로필·지도·합류 통과**: 이름 입력 후 진입, 설아 단독 시작, 두 이야기 노드에서 리라·아리아 순차 합류, 합류 때 파티와 덱 변경, 가로형 여정 배경·연결된 경로/세계 지도·모바일 내부 스크롤.
- **실제 Chromium 조작 통과**: 독립 메인 → 스테이지 → 전투, 대상 선택·턴 종료·첫 승리·보상·이벤트·저장 후 이어하기·덱/이야기 창. 무공/판타지 프레임과 기술 그림을 확인했다.
- **연출과 적용 시점 통과**: 균열·24조각 파쇄·발사 동안 행동력과 적 체력은 유지되고 적중 시 월하참 피해 9와 행동력 1 소비가 한 번 발생한다. 연출 중 숫자 키·턴 종료 입력을 차단한다. 동작 줄이기 설정에서도 정상 적용한다.
- **16종 카드와 세 절기 실제 사용 통과**: 유효한 저장 상태로 카드별 연출 완료, 월영천광·천체연쇄·서광성역의 효과, 게이지 100 소비·행동력 유지·선택창 닫힘을 검사했다. 보스 전장과 카드 컬렉션도 검사했다.
- **다중 화면 크기 통과**: 1440×1060, 1440×900, 1366×768, 1000×900에서 데스크톱 전장과 손패가 화면 안에 들어온다. 390×844 모바일에는 손패 가로 스크롤과 페이지 세로 스크롤을 사용하며 페이지 가로 넘침이 없다. 카드 설명은 카드 내부에 들어온다.
- **기존 진행 회귀 통과**: 야영 강화, 상인 구매·제거, 이벤트 강화, 다음 장 이동, 최종 엔딩, 새 원정, 잘못된 JSON 거부.
- 브라우저 JavaScript 오류 0건, 에셋 HTTP 실패 0건. 로컬 에셋을 포함한 정적 빌드를 검증했다.

재현: `npm start`, `npm test`, `npm run build`, `python tests/browser_check.py`, `python tests/browser_phases.py`, `python tests/browser_combat.py`. 브라우저 검사는 Python Playwright와 Chromium이 필요하다. `GAME_URL`과 `CHROMIUM_PATH`로 서버 주소·실행 파일을 지정할 수 있다.

`docs/v4-title.webp`, `v4-stage.webp`, `v4-battle.webp`, `v4-story.webp`, `v4-mobile.webp`는 실제 브라우저 화면이다. SD 캐릭터 3명·몬스터 6종에는 각 6프레임 공격, 기술 16종에는 각 4프레임 시트를 포함했다.

새 합류 진행과 합격절기를 사용하는 휴리스틱 플레이어를 30개 시드에서 실행해 모두 엔딩에 도달했다. 체력·덱 치트 없이 실제 규칙을 사용한다. 이 결과는 진행 가능성 확인이며 사람의 재미·난이도 평가를 대신하지 않는다. 상용작과 비교한 빌드 다양성에는 추가 콘텐츠가 필요하다.
