# 검증 기록

2026-10-05, 도트 그래픽·화면 분리 v2 기준.

- **엔진 검사 20개 통과**: 기존 전투 자원, 연계, 공명, 방어·약화, 사망, 카드 순환, 보상, 강화·제거, 저장 검증, 마교주 필수 조우, 4장 엔딩 규칙을 유지했다.
- **데스크톱 Chromium 1440×1060 실제 조작 통과**: 메인 → 원정 시작 → 스테이지 → 전투. 메인/스테이지에 전장과 손패가 없고, 전투에 경로 지도가 없는 것을 확인했다. 초상화·배경·카드·적 에셋과 한글 도트 폰트 로드 실패 없음.
- **카드 연출 검사 통과**: 상승·균열·투사체 동안 체력과 행동력은 유지된다. 적중 단계에서 기본 월하참의 피해 9와 행동력 1 소비가 한 번 적용된다. 카드 연출 중 숫자 키와 턴 종료 입력을 차단한다. 감소된 동작 설정에서도 중복 소비 없이 사용된다.
- **진행 UI 검사 통과**: 대상 선택, 턴 종료, 저장 후 메인에서 이어하기, 덱 14장과 이야기 창, 실제 버튼으로 첫 전투 승리, 보상 건너뛰기, 이벤트 후 다음 경로 선택.
- **모바일 Chromium 390×844 검사 통과**: 메인·스테이지·전투 및 덱 창에서 페이지 가로 넘침 없음. 손패는 가로 스크롤이며 카드 설명이 카드 내부에 들어온다. 적 선택·카드 사용·스테이지 이동 정상.
- **추가 상태 검사 통과**: 유효한 저장 상태를 준비해 야영 강화, 상인 구매·제거, 이벤트 강화, 다음 장 이동, 최종 엔딩, 새 원정의 스테이지 시작, 잘못된 JSON 거부를 검증했다.
- **정적 빌드 통과**: `dist/`에 소스와 로컬 에셋을 포함한다. 런타임 패키지 설치와 외부 폰트/API 호출이 필요 없다. 상대 경로로 Pages 저장소 하위 경로를 지원한다.
- 브라우저 JavaScript 오류 0건, 에셋 HTTP 실패 0건.

재현: `npm start`, `npm test`, `npm run build`, `python tests/browser_check.py`, `python tests/browser_phases.py`. 브라우저 검사는 Python Playwright와 Chromium이 필요하다. 서버 주소는 `GAME_URL`, 실행 파일은 `CHROMIUM_PATH`로 지정할 수 있다.

`docs/v2-title.webp`, `v2-stage.webp`, `v2-battle.webp`, `v2-mobile.webp`는 실제 브라우저 화면이다. 캐릭터 동작은 스프라이트 이동 기반이며, 여러 자세를 그린 프레임 시트는 아직 포함하지 않았다.

기존 v1의 캠페인 휴리스틱 검사에서는 기본 덱과 방어·회복 선택으로 30개 시드 모두 엔딩에 도달했다. 이번 변경은 전투 밸런스 수치를 바꾸지 않았다. 사람의 재미와 체감 난이도는 별도로 평가해야 한다.
