# 검증 기록

2026-10-05, 첫 플레이 가능 버전 기준.

- **엔진 검사 20개 통과**: 행동력, 파티 연계, 공명 소비, 방어·약화, 전투 불능, 전체 공격, 카드 순환, 카드 선택 보상, 야영 부활, 상인 거래, 강화·제거, 저장 검증, 장별 우두머리, 4장 엔딩, 마교주 필수 조우, 저장 파일 표시 데이터 정규화.
- **데스크톱 Chromium 실제 조작 통과**: 1440px에서 카드 사용, 대상 선택, 턴 종료, 새로고침 후 저장 복원, 지도·덱·이야기 창, 첫 전투 승리, 카드 보상 건너뛰기, 이벤트 후 다음 경로 선택. 페이지 JavaScript 오류 없음.
- **모바일 Chromium 검사 통과**: 390px 화면에서 적 선택과 카드 사용, 지도 열기, 페이지 가로 넘침 없음. 배경의 가로 잘림은 수정 후 다시 확인.
- **추가 화면 전환 검사 통과**: 유효한 저장 상태를 준비해 야영 강화, 상인 구입·제거, 이벤트 강화, 다음 장 이동, 최종 엔딩, 원정 초기화, 잘못된 JSON 불러오기 처리를 검증. Node 실행 서버 사용. 페이지 JavaScript 오류 없음.
- **캠페인 휴리스틱 시뮬레이션**: 기본 덱에서 시작한 30개 난수 시드 모두 4장 엔딩에 도달. 건강 상태를 고려해 방어와 회복을 선택하는 자동 플레이어를 사용하고 체력·행동력·적 체력을 변경하지 않음. 결과는 `balance-results.json`에 저장. 사람의 재미·체감 난이도 검증은 별도로 필요.
- **정적 빌드 및 구문 검사 통과**: 외부 런타임 의존성 없이 `dist/` 생성. 소스의 상대 경로로 Pages 하위 경로 배포 대응.

GitHub 소스 저장소: https://github.com/Taan9448/third. 공개 Pages 배포에는 저장소 Pages의 Source를 GitHub Actions로 설정해야 한다. 실제 배포 성공 여부는 Actions 결과로 확인한다.
